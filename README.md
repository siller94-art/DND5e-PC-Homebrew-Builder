# D&D 5e PC Homebrew Builder

Foundry VTT module for creating custom player-character content for the official D&D 5e system.

## Features
- Create native D&D5e PC content
- Supports classes, subclasses, feats/features, spells, backgrounds, and equipment
- Import homebrew content from PDF
- Import homebrew content from JSON
- Opens created entries in the native D&D5e item sheet for further editing

## Compatibility
- Foundry VTT 14.367+
- D&D5e 6.0.0+ (verified against 6.0.3)

## Install
Place the module folder in Foundry's Data/modules directory, then enable **D&D 5e PC Homebrew Builder** in your D&D5e world.

Version: 0.2.1
